## ข้อจำกัดของ Blockchain ปัจจุบัน

Private Blockchain เป็นบัญชีแฮชเชื่อมกันที่จำลองโหนดด้วยไฟล์ JSON 3 ชุดใน storage เดียว ใช้ข้อมูลที่ตรงกันอย่างน้อย 2 ชุดในการเลือกเชน ไม่ใช่โหนดเครือข่ายอิสระ หากผู้มีสิทธิ์เข้าถึงสามารถเขียนใหม่ทั้งฐานข้อมูลและทุกสำเนาเชน การตรวจภายในอย่างเดียวไม่เพียงพอพิสูจน์ว่าไม่มีการแก้ย้อนหลัง

มีระบบส่งแฮชไป Polygon Amoy เป็นหลักฐานภายนอกอยู่แล้ว แต่ต้องตรวจสถานะการยืนยันของแต่ละรายการแยกต่างหาก การตรวจเชนภายในผ่านไม่ได้แปลว่าได้ตรวจหลักฐานบน Polygon สำเร็จด้วย

## การตรวจสอบ

มีการทดสอบ API สำหรับการระงับบัญชี/การล็อกอิน การสร้าง QR การยืนยัน Paid การป้องกันเติมซ้ำ ยอดหรือเลขอ้างอิงไม่ตรงกัน และความสอดคล้องของฐานข้อมูลกับเชน โดยจำลองคำตอบจาก Opn และใช้ SQLite ในหน่วยความจำ

การใช้งานจริงต้องเปิด Laravel, queue worker, scheduler และ Reverb รวมถึงตั้งค่า Opn/webhook ให้เข้าถึงได้ การรันทดสอบเหล่านี้ไม่ได้โอนเงินจริงหรือส่งธุรกรรมจริงไป Polygon
